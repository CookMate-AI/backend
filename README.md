## ✨ 프로젝트 소개
**CookMate-Ai**는 냉장고 속 재료를 입력하면, AI가 해당 재료로 만들 수 있는 요리를 추천해주는 레시피 추천 플랫폼입니다.

- **서비스 개요**
  - AI 기반 요리 추천: 사용자가 입력한 재료를 기반으로 적합한 레시피를 AI가 자동으로 추천합니다.
  - 레시피 상세 정보 제공: 추천된 레시피는 모달을 통해 조리 방법, 필요한 재료, 유튜브 검색 링크와 함께 제공됩니다.
  - 레시피 저장 및 조회: 마음에 드는 레시피를 저장하고, 마이페이지에서 저장된 목록을 간편하게 확인할 수 있습니다.
- **특징 및 기대 효과**
  - 식재료 낭비 감소: 남은 재료를 활용한 요리 제안으로 음식물 쓰레기 감소에 기여할 수 있습니다.
  - 정보 탐색 시간 절약 : AI가 자동으로 레시피와 유튜브 검색 링크를 제공해서 사용자가 일일이 검색하지 않아도 됩니다.
- **기간** : 25.01 ~ 25.03
